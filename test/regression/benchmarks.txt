# PolyBench/NPDP regression benchmarks, read by benchmarks.cmake.
#
# One row per kernel. This is the only place to edit:
#
#   <suite>  <kernel>  <class>  <tested pipelines...>  [# why a pipeline is left out]
#
# * <class> decides what check-bench-probe runs (every pipeline of the class, see
#   PESTO_BENCH_CLASS_PIPELINES_* in benchmarks.cmake):
#     algebraic    standard and hybrid algebraic tiling;
#     trapezoidal  trapezoidal tiling only (generic tpz, or the hand-tuned per-kernel
#                  configuration in pipelines/handtuned/<suite>/<name>.json, which
#                  NPDP kernels need for its skew), never algebraic tiling;
#     unsupported  not pesto-compatible, only probed through Pluto.
#   "handtuned" is probed when the kernel has a hand-tuned configuration, "pluto"
#   when PESTO_BENCH_POLYCC is set.
# * <tested pipelines> become ctest cases (labels "regression;bench", part of
#   check-regressions). "-" means none. They must be pipelines the probe runs.
#   "pluto" cases are only registered when PESTO_BENCH_POLYCC is set.
# * Leaving a probed pipeline out of the tested ones needs a reason in a trailing
#   comment. Promote it once the probe report shows it passing.
#
# Add a kernel: add a row. Stop testing a pair: drop the pipeline from its row and
# say why. NPDP mea, sw3d and zuker are deliberately absent.
# Last checked against the probe report: 2026-11-26.
